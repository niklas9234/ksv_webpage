# KSV Webpage

## Entwicklung starten

Wenn beim Starten folgender Fehler erscheint:

```bash
npm run dev
# sh: 1: next: not found
```

fehlen die installierten Node-Module (insbesondere `next`).

### 1) Abhängigkeiten installieren

```bash
npm install
```

### 2) Dev-Server starten

```bash
npm run dev
```

Danach sollte Next.js wie erwartet starten.

## Voraussetzungen

- Node.js 20 oder neuer
- npm 10 oder neuer
